# Contributing

The goal is to learn and demonstrate engineering judgment, not just to copy multiple-choice answers.

1. Work from a new branch named `lab/NN-short-name`.
2. Read `docs/challenges/NN-*.md`.
3. Unlock the specific skipped test suite.
4. Verify a failing test before implementing.
5. Fix one challenge per pull request where practical.
6. Add at least one extra test and provide before/after evidence.
7. Run `pnpm test` and `pnpm typecheck`.
8. Document security, correctness and performance trade-offs.

Do not submit real tokens, secrets, datasets containing personal details, or unrelated refactors. Do not turn starter suites green by simply re-skipping them after implementing the exercise.
